一、Claude Code 接中转站的原理

Claude Code 官方客户端支持通过环境变量替换 API 端点。中转站提供与 Anthropic 官方相同格式的 /v1/messages 接口，所以只要改两个环境变量，不需要装任何插件：

# Windows PowerShell
$env:ANTHROPIC_BASE_URL = "https://你的中转站地址"
$env:ANTHROPIC_AUTH_TOKEN = "sk-你的中转站Key"
claude

# macOS / Linux
export ANTHROPIC_BASE_URL="https://你的中转站地址"
export ANTHROPIC_AUTH_TOKEN="sk-你的中转站Key"
claude
想长期生效，把两行写进 shell 配置（~/.bashrc / PowerShell $PROFILE）。Aimyria 的 Base URL 是 https://aimyria.com，注册后在控制台拿 Key 即可用上表环境变量直接接入。

二、怎么判断一家中转站「不降智」

「降智」指中转站偷偷把请求换成低配模型或削减上下文。三个可自查的信号：

1. 看响应头与模型名回显

让 Claude Code 执行 /status，确认返回的模型 ID 与购买的一致（如 claude-opus-5-5 而不是莫名的小型号）。

2. 用固定探针题测一致性

准备 3~5 个固定问题（长上下文摘要、代码推理），每天同一时间跑一遍，对比回答质量是否漂移。公开探测就是这么做的——下表「在线率」即来自每日探针序列。

3. 看长上下文表现

喂 50K+ token 的真实代码库任务，降智站通常在这一步露馅：回答变短、忘记前文、拒绝执行。

四、常见坑（实测踩过的）

坑 1：环境变量写错位置

PowerShell 的 $env: 只对当前会话生效，关窗即失效；写进 $PROFILE 才长期生效。CMD 用户要用 setx。

坑 2：Key 前缀混淆

部分站下发 sk- 开头 Key，也有站用自定义前缀；ANTHROPIC_AUTH_TOKEN 填的是中转站 Key，不是 Anthropic 官方 Key。

坑 3：混用官方与中转配置

同一台机器切换官方/中转时，残留的 ANTHROPIC_BASE_URL 会让官方 Key 打到中转站上。切换前先 echo $env:ANTHROPIC_BASE_URL 检查。

坑 4：只看价格不看样本

低于官方 1 折的 Opus 价格大概率伴随降智或超卖。上表价格与在线率放在一起看，才有参考价值。

五、FAQ

Claude Code 中转站和官方 API 什么区别？

接口格式一致，差别在计费（中转支持支付宝/微信、按量计费）与供给方式。官方账户在服务区且预算充足时仍是首选。

中转站跑 Claude Code 稳定吗？

头部站点近 30 天探针在线率可达 95%+（见上表），但任何中转都受上游配额影响，建议主力+备用双站配置。

Aimyria 怎么接入 Claude Code？

注册 aimyria.com → 控制台创建 Key → 按本文第一节设置 ANTHROPIC_BASE_URL 与 ANTHROPIC_AUTH_TOKEN 即可。有免费测试额度可先验证。
